# v0.3.1 工作项中心

本版本按照已冻结的 v1.0 路线推进，只聚焦“工作项中心 / 工单中心”，不增加额外模块。

## 新增

- 工作项中心页面升级为生产使用版 v0.3.1。
- 新增工作项统计接口：全部、今日新增、P1、P2、高风险、各状态数量。
- 工作项列表支持优先级筛选。
- 工作项详情新增快捷状态流转：开始处理、等待客户、标记解决、关闭。
- 右侧详情区支持更新分类与风险等级。
- 支持手动记录买家追加消息，方便 Amazon SP-API 接入前先保留完整时间线。
- 操作时间轴记录更多变更：状态、优先级、分类、风险等级、消息新增。

## 修复 / 优化

- 后端增加工作项状态、优先级、风险等级校验。
- 后端禁止保存空消息。
- 操作日志标题改为中文，便于内部客服查看。
- 页面文案统一为“工作项中心”。

## 数据库

- 本版本不新增表、不新增字段。
- 不需要新的 Alembic migration。

## 验收

1. 可以打开 `/workspace`。
2. 可以新建工作项。
3. 可以按状态和优先级筛选。
4. 可以打开工作项详情。
5. 可以保存客服回复。
6. 可以记录买家追加消息。
7. 可以切换状态并在右侧时间轴看到操作记录。
