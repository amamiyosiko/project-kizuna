# v0.2.2 - Production Docker Deployment

## 类型
Infrastructure / 部署稳定性

## 新增
- 新增 backend/Dockerfile。
- 新增 frontend/Dockerfile。
- 新增 backend/.dockerignore。
- 新增 frontend/.dockerignore。
- 新增根目录 .gitignore。

## 修改
- docker-compose.yml 改为 build 镜像方式。
- backend 不再每次启动时 pip install。
- frontend 不再使用 npm run dev。
- frontend 改为 npm install → npm run build → npm run start。
- 移除 frontend/package-lock.json，避免锁定到临时/本地 npm registry。
- 移除 frontend/tsconfig.tsbuildinfo。

## 解决的问题
- 修复前端 @swc/helpers 缺失导致的 500 / 502 问题。
- 避免 git clean 删除 node_modules 后前端无法启动。
- 减少服务器启动时重复安装依赖的风险。

## 部署命令
```bash
cd /www/wwwroot/project-kizuna.mychisyou.com
cp backend/.env /tmp/kizuna-backend.env.bak || true
git reset --hard
git clean -fd
git pull
cp /tmp/kizuna-backend.env.bak backend/.env
docker compose down
docker compose up -d --build
```
