# v0.3.4.1 Amazon SP-API 正式接入基础版

本版本继续保持路线冻结，只围绕 Amazon 接入目标推进。

## 新增

- 新增后端 SP-API 调用服务层。
- 支持 LWA refresh token 换取 access token。
- 支持 AWS SigV4 签名调用 SP-API。
- `/amazon` 页面新增“测试 SP-API 连接”。
- `/amazon` 页面新增“同步最近订单为工作项”。
- `/amazon` 页面新增“查询买家消息动作”。
- 保留手动导入买家消息，用于站内信无法自动拉取时继续使用同一套工作项流程。

## 安全边界

- 本版本不自动发送 Amazon 买家消息。
- 本版本不把 API 密钥显示在前端。
- 本版本不尝试读取受限 PII 数据。
- 订单同步采用幂等逻辑：同一店铺同一 Amazon Order ID 不重复创建工作项。

## 注意

Amazon SP-API Messaging API 当前主要用于查询订单可用消息动作和发送卖家到买家的消息，不等同于完整读取 Seller Central 站内信收件箱。因此 v0.3.4.1 的正式路线是：

1. 先打通 SP-API 正式连接。
2. 同步最近订单生成工作项。
3. 查询订单可发送消息动作。
4. 买家消息仍可通过手动导入进入工作项中心。
5. 后续确认 Amazon 账号权限后，再评估是否接入发送消息。
