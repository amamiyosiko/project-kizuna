# v0.3.7 Amazon SP-API 实际同步流程增强

本版本继续主线目标，只强化 Amazon SP-API 同步，不新增无关模块。

## 更新内容

- 增加 `amazon_sync_runs` 同步任务记录表。
- Amazon 订单同步支持有限分页，避免只拉第一页。
- 同步订单时写入 / 更新 `orders` 表。
- 同步订单时自动创建工作项；重复订单不会重复创建工作项。
- 订单状态变化时更新既有工作项时间线。
- `/amazon` 页面新增同步页数控制和同步任务记录。
- 同步成功 / 失败都会写入操作日志。
- 继续保持安全边界：不自动发送 Amazon 买家消息。

## 数据库

需要执行 Alembic 迁移：

```bash
docker compose run --rm backend alembic -c alembic.ini upgrade head
```

## 验收

1. 打开 `/amazon`。
2. 选择已开启 Amazon 同步的店铺。
3. 点击测试 SP-API 连接。
4. 点击同步最近订单。
5. 查看同步任务记录。
6. 打开 `/workspace`，确认新订单生成了工作项。
