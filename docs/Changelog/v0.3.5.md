# v0.3.5 基础权限 + 配置中心

## 目标

建立 Project Kizuna 的正式后台权限基础：账号归属角色，角色拥有权限，敏感配置由有权限的账号在后台维护。

## 更新内容

- 新增 RBAC 权限模型：User → Role → Permission。
- 内置四个角色：超级管理员、管理员、主管、客服。
- 新增权限点：用户管理、角色管理、配置管理、密钥管理、店铺管理、Amazon 同步、工作项、附件、AI、日志等。
- 系统设置页面新增账号管理。
- 系统设置页面新增角色权限管理。
- 系统设置页面新增配置中心。
- 配置中心支持 OpenAI、Gemini、Amazon SP-API 配置。
- 敏感配置加密保存，前端只显示脱敏值。
- 新增操作日志表，记录用户、角色、配置、店铺相关操作。
- 店铺管理增加 Marketplace ID 和 Amazon 同步开关。
- AI Provider 与 Amazon SP-API 优先读取数据库配置，其次读取 .env。

## 安全说明

- DATABASE_URL、JWT_SECRET_KEY、CONFIG_ENCRYPTION_KEY 仍然保留在 .env。
- OpenAI、Gemini、Amazon LWA 等业务密钥可以由超级管理员在后台配置中心维护。
- 密钥不会在前端回显完整内容。
