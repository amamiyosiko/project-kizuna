# v0.3.0 基础架构升级版

## 新增

- 引入 Alembic 数据库迁移框架。
- 新增 baseline migration：`20260628_0001_baseline`。
- 新增生产部署脚本：`scripts/deploy-production.sh`。
- 新增 `.gitattributes`，统一代码换行符为 LF，减少 Windows 提交提示。
- 新增数据库迁移说明文档。

## 调整

- `backend/requirements.txt` 增加 `alembic`。
- 保留当前 `Base.metadata.create_all()` 启动安全机制，避免现有生产数据库受到影响。

## 部署说明

本版本不强制执行 migration。当前生产数据库仍可直接启动。

建议部署后执行一次 Alembic baseline 标记：

```bash
docker compose exec -T backend alembic -c alembic.ini stamp head
```

后续版本开始使用：

```bash
docker compose exec -T backend alembic -c alembic.ini upgrade head
```
