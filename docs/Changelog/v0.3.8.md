# v0.3.8 配置中心重构 + 多店铺 Amazon 授权管理

## 目标

解决配置中心所有接口堆在一个页面、多店铺 Amazon 授权不清晰的问题。

## 更新内容

- 系统设置中新增独立入口：AI 配置、Amazon 全局配置、多店铺授权。
- 新增 `/settings/ai` 页面，单独管理 OpenAI / Gemini / 默认 Provider。
- 新增 `/settings/amazon` 页面，单独管理 Amazon 应用级配置：LWA Client ID、Client Secret、默认 Marketplace ID、Region。
- 店铺管理新增每家店铺的 Amazon Refresh Token 配置，支持多家店铺独立授权。
- 店铺管理显示 Refresh Token 是否已配置、脱敏值、最后同步时间。
- Amazon 接入页改为日常运营页面，只负责连接测试、订单同步、同步记录、手动导入，不再堆放密钥输入。
- Amazon 同步优先使用店铺级 Refresh Token 和店铺级 Marketplace ID。
- 新增数据库迁移：`20260629_0005_store_amazon_credentials`。

## 数据库变更

新增字段：

- `stores.amazon_refresh_token_encrypted`
- `stores.amazon_last_sync_at`

## 注意

- Amazon LWA Client ID / Client Secret 属于应用级配置，在 `/settings/amazon` 维护。
- Seller ID / Refresh Token / 同步开关属于店铺级授权，在 `/stores` 维护。
- Refresh Token 加密保存，前端不会回显完整值。
