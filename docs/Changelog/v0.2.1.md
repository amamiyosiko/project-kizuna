# Project Kizuna v0.2.1

## 新增

- 新增 Ticket 数据模型：`tickets`、`ticket_messages`、`ticket_events`。
- 新增 Ticket API：
  - `GET /api/v1/tickets`
  - `POST /api/v1/tickets`
  - `GET /api/v1/tickets/{id}`
  - `PATCH /api/v1/tickets/{id}`
  - `GET /api/v1/tickets/{id}/messages`
  - `POST /api/v1/tickets/{id}/messages`
  - `GET /api/v1/tickets/{id}/events`
- 重构 Workspace 为 Ticket 工作台。
- 支持新建 Ticket、查看 Ticket 列表、查看消息 Timeline、保存客服回复、修改状态和优先级。
- 删除 Workspace 假数据，空状态改为真实提示。

## 部署

```bash
cd /www/wwwroot/project-kizuna.mychisyou.com
git pull
docker compose up -d --build
```
