# v0.3.2 - S3 附件上传与预览

目标：只围绕当前工作项中心补齐附件能力，不增加额外模块。

## 更新内容

- 工作项详情右侧新增附件区域。
- 支持从工作项上传附件到 S3。
- 上传完成后写入 `attachments` 表。
- 支持附件列表、图片缩略图预览、打开 / 下载链接。
- 附件上传自动写入工作项操作时间轴。
- 附件接口兼容旧 Conversation 附件接口，同时新增 Ticket 附件接口。
- 新增 Alembic migration：`20260628_0002_ticket_attachments.py`。

## 数据库变更

`attachments` 表新增：

- `ticket_id`
- `ticket_message_id`

## 验收清单

1. 进入 `/workspace`。
2. 新建或打开一个工作项。
3. 在右侧“附件”区域上传一张图片。
4. 上传成功后应显示附件列表和图片缩略图。
5. 点击“打开 / 下载”能访问文件。
6. 操作时间轴出现“附件已上传”。

## 注意

本版本需要执行 Alembic 升级：

```bash
cd /www/wwwroot/project-kizuna.mychisyou.com
docker compose exec -T backend alembic -c alembic.ini upgrade head
```
