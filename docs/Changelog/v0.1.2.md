# v0.1.2 - Customer Workspace

## Added

- 新增 Customer Workspace 四栏工作台。
- 新增店铺筛选和状态筛选。
- 新增快速录入买家消息流程。
- 新增聊天记录查看区域。
- 新增 AI 工作区。
- 新增 AI 回复草稿编辑、复制、标记完成流程。

- Message 创建时会自动更新会话最后消息时间。
