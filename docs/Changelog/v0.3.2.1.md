# v0.3.2.1 附件上传修复

## 修复内容

- 修复浏览器直传 S3 成功前失败时不会写入 attachments 表的问题。
- 新增后端直传接口：`POST /api/v1/attachments/tickets/{ticket_id}/upload`。
- 前端附件上传改为 FormData 上传到后端，由后端使用 EC2 IAM Role 写入 S3 并保存数据库。
- 上传失败时前端显示明确错误。

## 数据库变更

- 无新增迁移。

## 验收

1. 新建或打开工作项。
2. 在右侧附件区域上传图片。
3. `attachments` 表出现记录。
4. 页面出现附件列表和图片预览。
