# v0.1.5 - KZ-009 回复模板

## Added

- 新增回复模板后端 CRUD 接口。
- 新增 `ReplyTemplateCreate`、`ReplyTemplateUpdate`、`ReplyTemplateOut` Schema。
- 新增模板管理页面：新增、编辑、删除、启用/停用、分类筛选。
- Customer Workspace 新增快捷模板区域。
- 默认种子模板：配送未到、商品破损、返品希望。

## Changed

- Workspace 打开时会同时加载启用中的模板。
- 模板内容可直接覆盖到 AI 回复草稿，方便客服二次编辑。

## Notes

- v0.1.5 仍然保持人工复制回复模式。
- 模板变量、订单字段自动替换、Amazon API 自动发送放到后续版本。
