# v0.3.4 Amazon SP-API 第一阶段接入

本版本只围绕既定目标推进：Amazon 接入准备。

## 已完成

- 新增 Amazon 接入页面 `/amazon`
- 新增 SP-API 凭证准备状态检查
- 后端新增 `/api/v1/amazon/status`
- 后端新增 `/api/v1/amazon/manual-import`
- 支持手动导入 Amazon 买家消息为工作项
- 手动导入会写入工作项、买家消息和操作时间轴
- `.env.example` 增加 Amazon SP-API 相关配置项

## 本版本不做

- 不自动调用 Amazon SP-API
- 不自动同步买家消息
- 不自动发送客服回复到 Amazon
- 不存储或展示真实密钥

## 验收

1. 打开 `/amazon`
2. 查看 SP-API 凭证状态
3. 选择 Amazon 店铺，手动粘贴一条买家消息
4. 点击“导入为工作项”
5. 到 `/workspace` 查看新工作项
6. 对该工作项测试 AI 回复和附件上传
