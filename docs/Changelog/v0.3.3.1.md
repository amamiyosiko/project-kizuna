# v0.3.3.1 AI Provider 双模型版

## 目标

在不改变当前 v1.0 路线的前提下，把工作项中心的 AI 回复助手升级为 GPT / Gemini 双模型可选架构。

## 更新内容

- 新增统一 AI Provider 层。
- 支持 OpenAI GPT 回复生成。
- 支持 Google Gemini 回复生成。
- 支持自动模式：优先使用配置的 AI_PROVIDER，失败后尝试另一个 Provider。
- 支持备用规则回复：AI API 未配置或调用失败时，客服工作不中断。
- 工作项详情右侧新增模型选择：自动 / GPT / Gemini / 备用规则。
- AI 生成结果显示使用 Provider、模型名称、是否降级备用规则。
- 操作时间轴记录本次 AI 生成使用的 Provider 和模型。

## 环境变量

```env
AI_PROVIDER=openai
OPENAI_API_KEY=sk-proj-xxxxx
OPENAI_MODEL=gpt-4.1-mini
GEMINI_API_KEY=xxxxx
GEMINI_MODEL=gemini-2.5-flash
```

`AI_PROVIDER` 可选：

- `auto`
- `openai`
- `gemini`
- `rule`

## 数据库

本版本不需要数据库迁移。
