# v0.2.3 Login Security Hotfix

## 新增/优化

- 登录页不再预填默认账号和密码。
- 登录页不再显示默认账号提示。
- 首次修改密码页不再预填旧密码。
- 前端依赖显式加入 `@swc/helpers`，减少 Next.js 运行时缺包风险。

## 部署说明

```bash
cd /www/wwwroot/project-kizuna.mychisyou.com
cp backend/.env /tmp/kizuna-backend.env.bak || true
git reset --hard
git clean -fd
git pull
cp /tmp/kizuna-backend.env.bak backend/.env
docker compose down
docker compose up -d --build
```
