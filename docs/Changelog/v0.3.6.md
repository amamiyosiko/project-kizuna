# v0.3.6 权限细化 + 正式配置流程

本版本继续 v0.3.5 的 RBAC 路线，不新增无关模块，只把权限和 Amazon 配置流程做得更适合正式使用。

## 更新内容

1. 后端接口开始按权限点强制校验，不再只判断是否登录。
2. 工作项、附件、AI、Amazon 同步等接口分别绑定对应权限。
3. 左侧菜单根据当前账号权限自动显示/隐藏。
4. 顶部显示当前账号与角色，方便确认登录身份。
5. Amazon 接入页增加正式配置入口：配置中心、店铺管理、角色权限。
6. Amazon 店铺准备状态增加“同步开关”判断，只有 Seller ID + 启用同步才算准备完成。
7. Next.js 增加页面 HTML 禁止缓存策略，减少刷新页面回旧版本的问题。

## 权限点强化

- `workitem.view`：查看工作项、时间线、附件列表。
- `workitem.create`：创建工作项、手动导入 Amazon 买家消息。
- `workitem.update`：修改工作项状态、分类、风险、优先级。
- `workitem.reply`：保存客服回复、AI 消息、手动追加消息。
- `attachment.upload`：上传附件。
- `ai.use`：使用 AI 回复助手。
- `amazon.sync`：测试 SP-API、同步订单、查询消息动作。
- `store.manage`：维护店铺资料、Seller ID、同步开关。
- `config.secret.manage`：维护 OpenAI / Gemini / Amazon 密钥。

## 数据库

不需要新增迁移。

## 部署

正常重新构建前端和后端即可。
