## Deployment
Use the standard deployment flow:

```bash
cp backend/.env /tmp/kizuna-backend.env.bak || true
git reset --hard
git clean -fd
git pull
cp /tmp/kizuna-backend.env.bak backend/.env
docker compose down
docker compose up -d --build
```
