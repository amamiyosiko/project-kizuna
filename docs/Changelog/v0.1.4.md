# v0.1.4 - KZ-008 S3 Attachments

## Added

- 新增 `attachments` 表模型。
- 新增 `/attachments/presign` 接口，用于生成 S3 Presigned PUT URL。
- 新增 `/attachments/confirm` 接口，用于保存上传成功后的附件记录。
- 新增 `/attachments/conversation/{conversation_id}` 接口。
- Workspace 新增附件上传区域。
- Workspace 新增会话附件列表展示。
- 新增 S3 环境变量配置。

## Notes

- 需要配置 AWS 凭证、S3 Bucket、Bucket CORS。
- 本版本不做附件公开访问控制、不做图片识别、不做 OCR。
