# KZ-006 Customer Workspace

版本：v0.1.2

## 目标

让客服在一个页面内完成 Amazon 买家消息的录入、查看、AI 日语回复生成、复制和处理状态更新。

## 本版本范围

- 四栏客服工作台布局
- 店铺筛选
- 状态筛选
- 快速录入买家消息
- 会话列表
- 聊天记录查看
- AI 工作区
- AI 日语回复草稿生成
- 回复草稿可编辑
- 复制回复
- 标记完成并写入客服消息记录
- 会话状态切换
- 内部备注输入框（前端预留）

## 会话状态

- open：未处理
- processing：处理中
- waiting_customer：等待客户
- done：已完成
- closed：已关闭

## 设计原则

V1 不追求复杂工单流转，而是优先实现客服每天最常用的动作：

1. 录入买家消息
2. 查看会话
3. 生成日语回复
4. 复制到 Amazon 后台
5. 标记完成

## 暂不包含

- Amazon API 自动同步
- Amazon API 自动发送
- 客户资料完整管理
- 订单/物流自动查询
- 内部备注持久化
- 附件上传

这些放到后续 KZ-007 / KZ-008 / Amazon Connector 阶段。
