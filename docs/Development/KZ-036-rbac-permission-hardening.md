# KZ-036 RBAC 权限细化与正式配置流程

## 背景

v0.3.5 已经建立“账号 -> 角色 -> 权限”的基础模型，并加入配置中心。v0.3.6 开始把权限真正应用到业务接口和前端导航，避免普通账号看到或调用不应该使用的功能。

## 范围

- 后端权限校验。
- 前端权限感知菜单。
- Amazon 正式接入配置入口优化。
- 页面缓存策略修复。

## 不在本版本范围

- 不做多角色叠加。
- 不做自动定时同步。
- 不做 Amazon 自动发送买家消息。
- 不做复杂组织架构。

## 验收

1. 超级管理员可以看到全部菜单。
2. 客服账号只看到工作项、AI/模板等日常处理入口，不能看到店铺、Amazon 接入、系统设置。
3. 没有权限时，直接调用 API 返回 403。
4. Amazon 页面显示配置中心和店铺管理的正式入口。
5. 直接刷新 `/workspace` 不再回到旧版本 HTML。
